# Интерактивный макет

Открыть `preview.html` в браузере. Нажатие на виджет раскрывает карточку слова; кнопка «Виджет» возвращает назад.

Это веб-макет для обсуждения внешнего вида, не запущенное iOS-приложение и не снимок Simulator. Произношение реализовано в SwiftUI-приложении, в макете его нет.

`word-daily.fragment.html` — исходный фрагмент макета для просмотра внутри Codex. В этом режиме настройки макета позволяют выбрать маленький/средний размер и посмотреть euphoria/lowkey. Отдельный `preview.html` содержит оболочку для обычного браузера.

Визуальное направление: крупная антиква, словарная композиция, спокойный фон, синий акцент. Исходное фото не включено в репозиторий; определения, примеры и переводы написаны для прототипа.

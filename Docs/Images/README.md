# Изображения для главного README

Подготовлены 13 ноября 2026 года из версии приложения `04e8eed`.

- `today-light.png`, `today-dark.png` — настоящие скриншоты приложения в iPhone 17 Pro Simulator с iOS 26.3. Сборка: Xcode 26.3, iOS Simulator SDK 26.2. Через `simctl status_bar` выставлены время 9:41 и заполненные индикаторы Wi-Fi и батареи.
- `widgets-light.png`, `widgets-dark.png` — рендеры маленького и среднего виджетов через SwiftUI ImageRenderer, масштаб 2×. Использован `DailyWidgetView` из `Widget/WordDailyWidget.swift` и первая карточка из `Shared/words.json`. Для рендера вне WidgetKit размер передан напрямую вместо read-only окружения `widgetFamily`; системный `containerBackground` заменён фоном и отступами 16 pt. Демонстрационные размеры — 170×170 и 364×170 pt, скругление — 26 pt. Внешний фон добавлен для презентации; это не скриншоты домашнего экрана iPhone.

Рендеры собраны во временной копии проекта. Код приложения и расширения в репозитории ради изображений не менялся. Параметры оформления виджетов на устройстве определяет iOS.
